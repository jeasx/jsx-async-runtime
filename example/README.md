# jsx-async-runtime-example

This is a simple example that showcases the main features of `jsx-async-runtime`: async components, escaping, the `this` context and `this.jsxToString` overrides.

First install dependencies in `jsx-async-runtime` (parent folder) and run a build:

```bash
npm install
npm run build
```

Then install dependencies in `example` project, run a build and start:

```bash
cd example
npm install
npm run build
npm start
```

Open <http://localhost:3000/> in your browser.
